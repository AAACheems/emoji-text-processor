## 📖 项目简介

Emoji 智能文本处理器是一款轻量级的网页应用，可以根据用户输入的文本内容，自动为匹配的关键词添加合适的 Emoji 表情符号。无论是社交媒体发帖、聊天消息还是日常写作，都能帮助您快速生成更加生动有趣的文本内容。

---

## ✨ 功能特点

### 🎯 核心功能
- **智能 Emoji 匹配**：基于语义理解，为文本中的关键词智能添加匹配的 Emoji
- **10+ 关键词分类**：涵盖天气、时间、地点、活动、情感、食物、动物、节日、工作、交通等类别
- **200+ 词汇支持**：支持丰富的中文词汇匹配
- **随机 Emoji 选择**：相同关键词每次会随机选择不同 Emoji，增加趣味性

### 🎨 个性化功能
- **自定义 Emoji 列表**：添加您常用的自定义 Emoji，持久化保存
- **主题切换**：支持暗色/亮色主题，一键切换，自动记忆
- **响应式设计**：完美适配桌面、平板和手机设备

### 🚀 交互体验
- **流畅动画**：页面加载、元素入场、交互反馈全程动画
- **即时反馈**：处理状态提示、复制成功提示、操作确认
- **快捷键支持**：`Ctrl + Enter` 快速处理文本

## 📖 使用指南

### 基本使用

1. **输入文本**：在左侧文本框中输入您想要处理的文本内容
2. **点击处理**：点击「智能处理」按钮或使用快捷键 `Ctrl + Enter`
3. **查看结果**：处理后的文本会显示在下方区域
4. **复制分享**：点击「复制结果」按钮，一键复制到剪贴板

### 文本示例

**输入文本：**
```
今天天气真好，我想去公园散步，然后喝一杯咖啡。
```

**处理结果：**
```
今天☀️天气真好，我想去公园🌳散步🚶，然后喝一杯咖啡☕。
```

### 自定义 Emoji

1. 点击「添加自定义」按钮
2. 在输入框中输入一个 Emoji
3. 点击「添加」按钮保存
4. 自定义 Emoji 会保存在浏览器本地，刷新后不会丢失
5. 悬停在自定义 Emoji 上可显示删除按钮

### 主题切换

点击右上角的「主题切换」按钮，可在暗色/亮色主题之间切换。主题设置会自动保存，下次打开会记忆您上次的选择。

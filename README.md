## 📖 项目简介

Emoji 智能文本处理器是一款轻量级的网页应用，可以根据用户输入的文本内容，自动为匹配的关键词添加合适的 Emoji 表情符号。无论是社交媒体发帖、聊天消息还是日常写作，都能帮助您快速生成更加生动有趣的文本内容。

---

## ✨ 功能特点

### 🎯 核心功能
- **三级精确匹配**：精确映射（词 → 专属 emoji）＞ 常用词映射 ＞ 分类兜底，杜绝「公园 → 🏬」这类错配
- **智能 Emoji 匹配**：基于 Trie 单次扫描 + 语义理解，为文本中的关键词智能添加匹配的 Emoji
- **14 大分类 + 157 常用词 + 158 精确映射**：涵盖天气、时间、地点、活动、情感、食物、动物、节日、工作、交通等类别
- **防重复堆叠**：关键词后紧跟 emoji 时不重复添加；同一词连续出现时自动切换不同 emoji
- **智能上限**：单次最多添加 24 个 emoji，避免表情刷屏

### ⚡ 效率体验
- **实时处理模式**：开启后输入即自动处理（防抖 550ms），所见即所得
- **示例一键填充**：内置 3 个示例文本，点击即可体验
- **快捷键支持**：`Ctrl + Enter` 快速处理
- **毫秒级响应**：Trie 一次扫描 + 缓存，2000 字文本处理 < 5ms

### 🎨 个性化功能
- **自定义 Emoji 列表**：添加常用自定义 emoji，持久化保存（最多 40 个）
- **主题切换**：暗色/亮色双主题，一键切换，自动记忆
- **结果高亮**：处理结果中的 emoji 以渐变胶囊高亮 + 弹跳入场动画
- **处理统计**：实时显示 emoji 数量与处理耗时

### 🌌 界面设计
- **流光动态背景**：三层漂浮光斑 + 微网格 + 噪点质感，暗/亮双主题自适应
- **毛玻璃卡片**：模糊、饱和、内高光、悬浮提亮
- **细节动效**：按钮光扫 + 涟漪、标题流光、徽章弹跳、Toast 进度条
- **响应式设计**：完美适配桌面、平板和手机
- **无障碍与动效偏好**：支持 `prefers-reduced-motion`，提供焦点环与 ARIA 标签

## 📖 使用指南

### 基本使用

1. **输入文本**：在文本框中输入内容，或点击示例一键填充
2. **点击处理**：点击「智能处理」按钮、使用快捷键 `Ctrl + Enter`，或开启「实时处理」
3. **查看结果**：处理后的文本会显示在下方，emoji 高亮呈现
4. **复制分享**：点击「复制结果」按钮，一键复制到剪贴板

### 文本示例

**输入文本：**
```
今天天气真好，我想去公园散步，然后喝一杯咖啡。
```

**处理结果：**
```
今天📅天气🌤️真好👏，我想去公园🌿散步🚶，然后喝一杯咖啡☕。
```

### 实时处理

点击输入框下方的「实时处理」开关，输入文字后会自动进行智能处理，无需手动点击按钮。

### 自定义 Emoji

1. 点击「＋自定义」按钮
2. 在输入框中输入一个 Emoji
3. 点击「添加」按钮保存
4. 自定义 Emoji 会保存在浏览器本地，刷新后不会丢失
5. 悬停在自定义 Emoji 上可显示删除按钮

### 主题切换

点击右上角的主题按钮，可在暗色/亮色主题之间切换。主题设置会自动保存。

## 🔧 技术栈

| 技术 | 说明 |
| :--- | :--- |
| HTML5 | 语义化标签结构 |
| CSS3 | 现代样式设计、动画、响应式布局、CSS 变量主题系统 |
| Vanilla JavaScript | 原生 JS，无任何框架依赖 |
| Trie 匹配引擎 | 单次扫描关键词匹配，构建后缓存 |
| Intl.Segmenter | 字素簇切分，正确渲染 ZWJ 组合 emoji |
| LocalStorage | 本地数据持久化存储 |

### 架构特点

- **零依赖**：无需安装任何 npm 包或构建工具
- **轻量级**：所有文件总计不到 70KB
- **快速加载**：首屏加载时间 < 100ms
- **加载即用**：无需网络，打开即可使用
- **匹配优先级**：精确映射 > 常用词映射 > 分类兜底，保证语义准确
